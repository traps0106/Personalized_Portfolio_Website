# Personalized Portfolio Website

## Description
This project is a professional personal portfolio website designed to showcase skills, interests, and contact information. It serves as a digital resume and a hub for professional networking.

## Key Features
- Hero Section: An introductory section with a welcoming message and professional summary.
- About Me: A personalized bio detailing educational background and career goals.
- Skills Section: A grid-based layout highlighting core competencies and hobbies using cards.
- Contact Form: A dedicated section for potential collaborators to reach out.
- Responsive Design: Fully optimized for various screen sizes using modern CSS and Bootstrap.

## Technology Stack
- HTML5: For structured page content.
- CSS3: For custom styling and layout.
- Bootstrap 5: For responsive grid systems and pre-styled components.
- Google Fonts: For enhanced typography.

## Project Structure
- index.html: Main entry point containing the website structure.
- styles.css: Custom stylesheet for layout and design refinements.
- Assets: Images and AVIF files used for profile and skill sections.
